สมุดเงิน — เวอร์ชันใช้งานส่วนตัวคนเดียว ไม่ต้องเข้าสู่ระบบ

วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ผ่าน VS Code Live Server หรือเว็บเซิร์ฟเวอร์ในเครื่อง (แนะนำ) ไม่ควรเปิด index.html ด้วย file://
3. เปิดหน้าเว็บแล้วเริ่มบันทึกรายรับ รายจ่าย บิล เงินเก็บ หนี้ และเป้าหมายได้ทันที
4. ใช้เมนูตั้งค่าและข้อมูลเพื่อสำรอง/ส่งออกข้อมูล และส่งออก Excel ได้

ไม่มีระบบ login
- เวอร์ชันนี้ไม่เรียก Supabase Auth และไม่แสดงหน้าเข้าสู่ระบบ/สมัครสมาชิก
- ข้อมูลใหม่บันทึกใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ได้ซิงก์ขึ้นคลาวด์
- ใช้เบราว์เซอร์เดิมบนอุปกรณ์เดิมเพื่อเข้าถึงข้อมูล
- การล้างข้อมูลเว็บไซต์/เบราว์เซอร์หรือเปลี่ยนอุปกรณ์อาจทำให้ข้อมูลหาย ควรสำรอง JSON และส่งออก Excel เป็นประจำ
- แอปพยายามย้ายข้อมูลใน localStorage จากเวอร์ชันก่อนที่ใช้ key แยกตามบัญชี Supabase โดยเลือกชุดข้อมูลที่มี updatedAt ล่าสุด หากข้อมูลเก่าอยู่เฉพาะใน Supabase จะไม่สามารถดึงมาได้เมื่อไม่มีการเข้าสู่ระบบ

ข้อมูลใน Supabase เดิม
- การเอา login ออกไม่ได้ลบข้อมูลใน Supabase แต่เวอร์ชันนี้จะไม่อ่านหรือเขียนข้อมูลออนไลน์
- หากข้อมูลเดิมอยู่ในคลาวด์เท่านั้น ให้ใช้เวอร์ชันที่มี login เดิมเข้าสู่ระบบและส่งออกข้อมูลก่อน แล้วจึงนำเข้าหรือกู้คืนในเวอร์ชันนี้เมื่อมีฟังก์ชันนำเข้าที่รองรับ
- อย่าลบ Supabase project หรือ finance_data หากยังต้องการเก็บข้อมูลเดิม

Excel
- ส่งออกข้อมูลเป็นไฟล์ .xlsx ได้
- finance-template.xlsx เป็นเทมเพลตเปล่า ไม่ใช่การซิงก์อัตโนมัติระหว่าง Excel กับเว็บ

ความเป็นส่วนตัว
- เพราะไม่ต้อง login จึงไม่มีการแยกสิทธิ์ผู้ใช้ หากคนอื่นใช้เบราว์เซอร์/อุปกรณ์เดียวกัน อาจเห็นข้อมูลของคุณ
- ไฟล์ HTML/JS ไม่ควรใส่ secret key หรือ service_role key
